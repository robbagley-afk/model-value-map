Model upgrades

When a newer model beats its predecessor at every effort for less money, the old model leaves the map. This page shows what changed.

No model has retired yet.

The rule

An older model retires only when its newer successor beats it at every effort the old model has. The successor must have the same effort. Both rows must use the current AA Intelligence Index version. The successor index must be higher and its cost must be lower. Ties do not qualify.

Why none qualify today

  • Grok 4.6 to Grok 4.7: Grok 4.6 high row is unversioned, not v5.0. Grok 4.6 low row is unversioned, not v5.0. Grok 4.6 xhigh row is unversioned, not v5.0. Grok 4.7 has no medium effort.

Rows that still use an older AA index version cannot be compared with current rows. The old model stays on the map until a fair comparison exists.
