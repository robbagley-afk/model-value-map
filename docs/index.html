When to use it

Before you choose a model for a new task, set up a scheduled run, or write instructions for an AI tool. Also when your usage limit or bill climbs and you need to know what to downgrade.

Why it pays

Scores climb slowly while cost climbs fast. The top setting can cost hundreds of times more than a small model for about twice the score, and some cheaper models match pricier ones outright.

How to use it

Find your kind of work under Sweet spots below and take the listed pick. Move up to the upgrade only if the pick fails. To explore, choose a test, filter by vendor, and hover a dot for its cost. The ringed dot is the best value on that view. Then copy the instruction text near the bottom into Claude, ChatGPT, or Codex so they choose this way by default.

Install the AI Token Saver plugin

The plugin asks this guide for the current pick each time you use it and cites the Revision, so nothing here needs re-pasting when picks change. It is free, read-only and needs no account. To install, copy one prompt and paste it into the AI app you want it in. An app with a terminal installs and checks it. A chat app replies with the exact clicks. Install one edition per app.

All Platforms edition

For people who use more than one of Claude, ChatGPT, Codex, Gemini or Grok. After install it asks which platforms you use and builds one setup prompt. That prompt adds the guidance to your instructions and one refresh task on each platform, every two weeks on Saturday at 10 PM, and keeps only one such task active.

Install the AI Token Saver (All Platforms) plugin for me. Source: https://github.com/robbagley-afk/ai-token-saver

1. Work out which app you are. Check whether it is already installed and say so instead of installing twice.
2. Show me the commands you will run, then run them:
   - Claude Code: `claude plugin marketplace add robbagley-afk/ai-token-saver` then `claude plugin install ai-token-saver-all@ai-token-saver`
   - Codex: `codex plugin marketplace add robbagley-afk/ai-token-saver` then `codex plugin add ai-token-saver-all@ai-token-saver` These commands write to ~/.codex. If the sandbox blocks them with “Operation not permitted”, request approval to run them outside the sandbox. If approval is unavailable, give me both commands to run in my own Terminal and wait until I say done before verification. After an attempted install, inspect the installed state before retrying to avoid duplicates.
   - Any other agent with a shell (Gemini CLI, Antigravity and similar): add `https://ai-token-saver.vercel.app/mcp` as a Streamable HTTP MCP server named ai-token-saver with no authentication, using the command or config file your own documentation gives. Then save https://raw.githubusercontent.com/robbagley-afk/ai-token-saver/main/plugins/ai-token-saver-all/skills/model-guidance-all/SKILL.md into your skills folder as model-guidance-all/SKILL.md. If you have no skills folder, tell me and stop after the server is added.
   - A chat app with no shell (ChatGPT, Claude, Gemini or Grok in a browser or phone): you cannot install it yourself. Give me the exact clicks to add a custom MCP server or connector with the address https://ai-token-saver.vercel.app/mcp and no authentication, and tell me if my plan or workspace admin may block it.
3. Verify. List the installed plugins or MCP servers and confirm AI Token Saver is there. If the get_guidance tool is available in this chat, call it once with my platform and show me the Revision. If it only loads in a new chat, say so.
4. Finish with one line: INSTALLED, ALREADY INSTALLED, CLICKS NEEDED, or FAILED with the exact error. Then tell me to start a new chat and ask "Recommend a model and effort for this task. Cite the Revision."

Rules: do not edit my instruction files or account settings, do not create scheduled tasks, do not install anything else, and if a command fails show the error and stop, except for the explicit sandbox permission recovery above. In that case request outside-sandbox approval or provide the manual commands, wait for completion, and verify before continuing.
