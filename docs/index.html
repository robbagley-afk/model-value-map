When to use it

Before you choose a model for a new task, set up a scheduled run, or write instructions for an AI tool. Also when your usage limit or bill climbs and you need to know what to downgrade.

Why it pays

Scores climb slowly while cost climbs fast. The top setting can cost hundreds of times more than a small model for about twice the score, and some cheaper models match pricier ones outright.

How to use it

Find your kind of work under Sweet spots below and take the listed pick. Move up to the upgrade only if the pick fails. To explore, choose a test, filter by vendor, and hover a dot for its cost. The ringed dot is the best value on that view. Then copy the instruction text near the bottom into Claude, ChatGPT, or Codex so they choose this way by default.

Install the AI Token Saver plugin

The plugin asks this guide for the current pick each time you use it and cites the Revision, so nothing here needs re-pasting when picks change. It is free, read-only and needs no account. To install, copy one prompt and paste it into the AI app you want it in. An app with a terminal installs and checks it. A chat app replies with the exact clicks. The ChatGPT and Codex edition is retired. If you have it, this prompt offers to remove it after the new one works.

Install prompt (version 0.5.8)

Works in Claude, ChatGPT, Codex, Gemini and Grok. After install it asks which platforms you use and builds one setup prompt. That prompt adds the guidance to your instructions and one refresh task, at 1:00 PM local time on the first Tuesday of each month. Each answer gives a Recommendation and a Budget choice. Keep one task per chat: start a new chat for each new task.
